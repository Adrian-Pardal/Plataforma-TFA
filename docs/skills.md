# Skills do projeto

Skills ficam em `.claude/skills/<nome>/SKILL.md`. O índice (nome, tipo, fase e
o que faz) está em [.claude/skills/README.md](../.claude/skills/README.md).

- **Documentação de cada skill:** o próprio `SKILL.md` (conceito, passos,
  "Proibido" e "Como verificar"). Skills NÃO ganham página em docs/help.
- **Como usar (manual × automática):** [help/ferramentas/skills.md](help/ferramentas/skills.md).
- **Criar skill nova:** formato e regras seguem o guia do projeto; atualize
  o índice no mesmo commit.
