# Skills do projeto

Cada skill é uma pasta `<nome>/SKILL.md`. Skills "manuais" só rodam quando
você digita `/<nome>`. Como usar: [docs/skills.md](../../docs/skills.md).

Fases: spec, plano, implementação, revisão, fechamento, sessão, transversal.

| Skill | Tipo | Fase | O que faz |
|-------|------|------|-----------|
| [entrevista-spec](entrevista-spec/SKILL.md) | manual | spec | Entrevista uma pergunta por vez e escreve a spec da feature |
| [planejar](planejar/SKILL.md) | manual | plano | Transforma uma spec Aprovada em plano com tasks pequenas, ligadas a critérios e testes |
| [implementar-tdd](implementar-tdd/SKILL.md) | manual | implementação | Implementa uma task do plano em TDD (vermelho, verde, refatorar) com verificação final e push |
